Import & Compare

Import the IRBA/IAASB handbook PDF and the Excel WP mapping file here, and review any flagged differences between handbook versions. The first handbook PDF import for a standard sets its baseline Official Standard Text directly, no review step. Importing a newer edition of that PDF later compares it against the existing baseline paragraph by paragraph, and you Accept or Dismiss each difference. Excel WP mapping import works independently, populating the WP Extract column.

1Import the IRBA/IAASB handbook (PDF)

Two separate imports, done once each per handbook edition: first set the baseline, then later compare a new edition against it. A paragraph number that's gone missing on comparison is flagged as Not Found for manual review only — it's never deleted automatically. Accepting a flagged difference replaces the baseline and keeps the old version in that paragraph's history.
No standards PDF has been imported yet.

Step 1Set baseline

Use this the FIRST time you import a handbook for a standard. Reads numbered requirement paragraphs (not explanatory/application material) straight out of the PDF and writes them into Official Standard Text on Coverage Review as the locked baseline — applied immediately, no review queue. Standards that already have a baseline are left untouched by this button — use Step 2 for those.

Step 2Compare new version

Use this once a newer handbook edition is released. Compares the new PDF against the existing baseline paragraph by paragraph and flags every difference (Update Body / Renumbered / New Paragraph / Not Found) for you to Accept or Dismiss on Coverage Review or below — nothing is overwritten until you Accept. Standards with no baseline yet are skipped by this button — use Step 1 for those first.

2Import WP mapping (Excel)

Populates the Draftworx WP extract, WP reference, comments and expected-compliance-area tick marks for each paragraph directly from your existing Excel mapping file — applied immediately so you can compare it against the standard text. Supports multi-level paragraph references split across separate columns (main number, letter, roman numeral, sub-letter, sub-sub level), combined into one reference like "25(d)(iii)". Not sure of the exact layout? Download the template below.
